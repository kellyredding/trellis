### 📐 Even gaps, measured in points
- A region's gap is now in points: one number for both directions (`"gap": 10`), or `{"x": …, "y": …}`. Windows side by side and windows stacked sit the same distance apart on every display.
- Every window in a region is exactly one gap from its neighbours, so a three-way stack is three equal windows. Halves and corners land where they did.
- A 0.1.0 config with gaps in fractions of the screen is refused until they're converted, and the error names each one. Edit the file (`"gap": 10` is a good start), then run `trellis config validate`. Margins are unchanged.

### 🩺 A doctor that checks the install
- `trellis doctor` checks the installed app's build commit and signer, and the installed CLI's checksum, against the install record, and lists any other Trellis.app that Launch Services knows.
- Settings → About shows the commit a release was built from instead of "development build".

### 🛠️ Fixes
- After a config change, a reload the app accepts but doesn't answer is reported as unconfirmed, not as Trellis not running.
