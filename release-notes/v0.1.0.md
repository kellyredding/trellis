### ⌨️ Layout mode on one key
- Press ⌃S and a label appears on every screen; the next chord places the focused window. Record a different leader in Settings by pressing it.
- A chord can be several keys. One that also starts a longer chord waits 600 ms for the next key, and one that starts nothing runs at once.
- After a chord, the label stays a moment to show what ran, with a tick or the reason it failed.

### 📐 Layouts are data
- A placement is a rect in fractions of the screen, optionally inside a region that keeps margins clear and gaps between neighbouring windows. Bindings map chords to placements, or to moving a window to the next display.
- Every binding belongs to a named group, and Settings shows the bindings group by group, in the order you set.
- It all lives in one JSON file, which can be a symlink into your dotfiles. The starter binds halves, quarters, 60/40 splits, the whole screen and the next display.

### 🤖 A CLI built for agents
- `trellis windows` lists every window, `trellis place --rect` tries a shape without saving it, and `trellis bind` and `trellis resolve` add a chord and say what one does. Every command except `update` takes `--json`, and its exit code tells a missing app from a missing permission from a window it couldn't find.
- The CLI is the config's only writer: it validates the whole file before writing, and tells the app to reload. An invalid file never goes live; the app keeps its last good config and names the error in its menu.

### 🔏 Signed, installed with one command
- Trellis.app and the CLI are signed with Trellis's own release certificate, so the Accessibility permission survives updates, and the installer refuses anything signed otherwise.
- `trellis update` installs the latest release, and `trellis doctor` checks the CLI, the config and the app.
- Without the Accessibility permission, the menu-bar icon dims and shows a "!".
